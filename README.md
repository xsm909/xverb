# Xverb

A dual-pane file manager in the Total Commander tradition, built entirely in
Flutter and extended with Python plugins.

The core does one thing: manage files in two panels. Everything else — network
transports, viewers, editors, archive support — is a plugin. The catalogue is
at [xsm909/xverb-plugins](https://github.com/xsm909/xverb-plugins), and
releases are published to
[xsm909/xverb-release](https://github.com/xsm909/xverb-release).

**Open source, not open development.** What lands here is a working state,
whole and buildable, under GPL-3.0 — so a single commit can touch four hundred
files and the build number can jump between them. The number in a commit is the
number on the archive somebody downloaded, so a bug report that cites one lands
exactly.

Nothing is published here yet.
